# Changelog — native tool `app_functions`

All notable changes of this feature are recorded here once they are released.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/): one
line per change, newest release first, grouped as Added, Changed, Deprecated,
Removed, Fixed, Security.

This project keeps **no `[Unreleased]` section**: what is done but not yet
released is listed in [ROADMAP.md](ROADMAP.md) under "Done, not yet released",
and moves here, with a version and a date, when the release is made. The
branch is based on Minis release 1.15 and has no release of its own yet.
